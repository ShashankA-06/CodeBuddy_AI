# CodeBuddy AI

An AI-powered coding assistant built with Python, Streamlit, and the Google Gemini API.

## Working Procedure

1. **Launch the App:** Open the CodeBuddy AI web interface in the browser.
2. **Choose a Feature & Input Code:** Select a mode (Code Explanation, Code Conversion, Error Debugging, or Code Generation) and enter your code or prompt.
3. **Generate Response:** The application sends the input to the Gemini API and displays the formatted result on screen.
